# Jigsaw Puzzle

Кроссплатформенная игра-пазл на C++ с использованием библиотеки [Raylib](https://www.raylib.com/).

Игрок выбирает изображение, задаёт сложность (количество кусочков) и собирает пазл, перетаскивая и поворачивая фигурные кусочки. Каждый кусочек имеет уникальную форму, генерируемую параметрически с помощью гауссовых кривых.

## Особенности

### Геймплей

- **Выбор изображения** — из папки `assets/images/` (поддерживаемые форматы: `.png`, `.jpg`, `.jpeg`, `.bmp`)
- **Пресеты сложности** — от 5×5 (25 кусочков) до 32×32 (1024 кусочка)
- **Партикки с уникальной формой** — параметрическая генерация контуров через гауссовы кривые; каждый край (верх, право, низ, лево) имеет свой `edgeId`, `tabLength`, `tabWidth`, `curvatureA`, `curvatureB`, `asymmetry` и `jitter`
- **Система примагничивания (Snap System)** — кусочки автоматически соединяются, когда оказываются в правильном положении с правильными комплементарными краями
- **Неделимые блоки** — соединённые кусочки объединяются в единый блок, который можно перемещать и поворачивать целиком
- **Анимация соединения** — плавное выравнивание с easing (150 мс)
- **Завершение пазла** — поздравительный экран с опциями «повторить», «другое изображение», «в меню»

### Управление (десктоп)

| Действие | Клавиша / Мышь |
|---|---|
| Переместить блок | ЛКМ + перетаскивание |
| Выбрать блок | Клик ЛКМ |
| Повернуть блок | ПКМ |
| Панорама фона | СКМ / перетаскивание фона |
| Масштаб | Колесо мыши |

### Управление (Android / тачскрин)

| Действие | Жест |
|---|---|
| Переместить блок | Один палец на кусочке |
| Панорама фона | Один палец на фоне |
| Масштаб | Pinch-zoom двумя пальцами |
| Повернуть блок | Кнопка «Повернуть» в HUD |

### HUD (игровой экран)

Кнопки масштабирования: `+` (zoom in), `−` (zoom out), `0` (reset), `F` (fit all)
Индикатор прогресса: `X / Y` (соединено кусочков из общего числа).

## Сборка

### Требования

- **Компилятор:** GCC / Clang / MSVC с поддержкой C++17
- **CMake:** версия 3.25 или выше
- **Raylib:** установлен локально (по пути `C:/raylib` на Windows или аналогичному)
- **Для Android:** Android NDK 25+, Android SDK, Gradle

### Десктоп (Windows, Linux, macOS)

```bash
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release
```

Бинарник появится в `build/`. Скрипт `POST_BUILD` автоматически копирует `assets/` в директорию сборки.

> **Примечание:** Путь к raylib в `CMakeLists.txt` (`C:/raylib/raylib`) нужно скорректировать под вашу систему.

### Android

```bash
cd android
# Сборка и установка APK на подключённое устройство
.\build-android.bat
```

Отладка через `adb logcat`.

## Настройки

Настройки сохраняются в файл `saves/settings.json`:

| Параметр | Значения по умолчанию | Описание |
|---|---|---|
| `uiScale` | `1.0` | Масштаб интерфейса (0.75 / 1.0 / 1.25) |
| `difficulty` | `1` | Пресет сложности |
| `fullscreen` | `false` | Полноэкранный режим |
| `volume` | `1.0` | Общая громкость |

Прогресс сборки сохраняется автоматически (текущее изображение, расстановка кусочков, время игры).

## Архитектура

Игра построена на **конечном автомате состояний**:

```
MainMenuState → MenuState → PlayState → CompletedState
       ↑            ↓                           │
       └──── SettingsState ──────────────────────┘
```

### Ключевые компоненты

| Модуль | Описание |
|---|---|
| **PuzzleGenerator** | Создаёт сетку кусочков, генерирует формы через `PieceShapeGenerator`, извлекает текстуры |
| **PieceShapeGenerator** | Параметрическая генерация контуров: Gaussian-кривые, уникальные `edgeId`, комплементарность Tab/Blank |
| **SnapSystem** | Проверяет правильность соединения: соседство в сетке, комплементарность краёв, порог расстояния |
| **CameraController** | Панорама, зум (относительно курсора / pinch-центра), `FitRectangle`, `Reset` |
| **SaveManager** | JSON-сериализация прогресса и настроек |

## Форматы изображений

Поддерживаемые форматы: `.png`, `.jpg`, `.jpeg`, `.bmp`.

Изображения размещаются в папке `assets/images/`. Каталог автоматически сканируется при запуске. Для принудительного обновления каталога (при добавлении новых изображений) выполните полную пересборку (`cmake --build .`) — она скопирует файлы из `assets/` в директорию бинарника.
